# 60+ Columns Survey Data

## Project Overview
This project contains survey-style data and a Power BI reporting model created to explore a wide-table dataset across many respondent and response dimensions.

## Data
The project is built around a spreadsheet-based survey dataset with a high number of columns and supporting analytical modeling assets.

## Solution
The report and semantic model were designed to enable exploratory analysis across categories and survey attributes.

## Technologies
- Power BI
- Excel workbook data
- semantic model design
- report layer
